# Guion para video demostrativo (5–10 minutos)

Grabar la ejecución real; este guion no reemplaza el archivo de video ni demuestra pruebas que no se hayan ejecutado. Mostrar a los integrantes del equipo según la instrucción del curso y evitar datos personales o secretos en pantalla.

1. **0:00–0:45 — Problema y solución:** presentar el restaurante y los módulos principales.
2. **0:45–1:30 — Arquitectura:** enseñar `src/RestauranteApp`, `database`, `docker`, `docs`; explicar ASP.NET Core, EF Core y SQL Server.
3. **1:30–3:30 — CRUD y roles:** demostrar menú/categorías/mesas con una cuenta de prueba autorizada.
4. **3:30–4:30 — Pedido y cocina:** crear un pedido de demostración y mostrar su recorrido.
5. **4:30–5:45 — FAQ público:** preguntar por menú, categoría, descripción, precio y recomendación. Mostrar que los productos agotados y los conteos de inventario no se revelan.
6. **5:45–6:30 — API y base de datos:** mostrar el endpoint del FAQ y que devuelve datos del menú sin información privada.
7. **6:30–7:30 — Docker:** ejecutar Compose y abrir la aplicación en el puerto 8080.
8. **7:30–8:30 — Azure:** enseñar el sitio y la ejecución exitosa del workflow, ocultando identificadores/secretos.
9. **8:30–9:30 — Pruebas y límites:** mostrar resultados realmente ejecutados y aclarar que el FAQ usa reglas, no IA generativa. El requisito de IA debe validarse con el docente respecto a la propuesta aprobada.

Completar el tiempo restante con retos encontrados, lecciones aprendidas y participación del equipo.
